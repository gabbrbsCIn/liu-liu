# Diário do Leão

App pessoal para registrar os jogos do Sport que eu fui ver, com fotos, setor e estatísticas.

- `REQUISITOS.md`: requisitos da v1, dados iniciais e perguntas em aberto.
- `design/prototipo.html`: protótipo navegável com os 94 jogos (Resumo, Jogos, detalhe do jogo, Adversários e Registrar jogo). Abra o arquivo no navegador; o que for registrado nele some ao recarregar.
