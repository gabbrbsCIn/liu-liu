# Diário do Leão

App para registrar os jogos do Sport que eu fui ver, com fotos, setor e estatísticas, usando dados de partidas da API da ESPN.

- `REQUISITOS.md`: requisitos, teste de viabilidade das APIs, modelo multiusuário e perguntas em aberto.
- `design/prototipo.html`: protótipo navegável com os 94 jogos e os dados reais da ESPN para 84 deles (Resumo, Jogos, detalhe do jogo, Adversários, Montar diário e Registrar jogo). Abra o arquivo no navegador; o que for registrado nele some ao recarregar.

O app deve ganhar um repositório próprio; esta pasta é provisória.
